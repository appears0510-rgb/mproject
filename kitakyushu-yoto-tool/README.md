# 北九州市 用途地域・建ぺい率・容積率 検索ツール

住所を入力するだけで、その地点の**用途地域・建ぺい率・容積率**を検索できる社内用ツールです。重要事項説明書を作成する際の下調べを補助する目的で作っています。

## できること / できないこと

- できること: 用途地域、建ぺい率、容積率、区域設定年月日、告示番号などを住所から自動取得します（データ元は国交省「不動産情報ライブラリ」の都市計画決定GISデータ）。
- できないこと: 防火・準防火地域、高度地区、地区計画、前面道路の種別・42条2項道路の該当有無、災害関連区域などは、このデータには含まれていません。重要事項説明書に記載する際は、必ず北九州市都市計画課の窓口や「G-motty」で最終確認してください。
- あくまで参考情報です。法的な証明力はありません。

## 事前準備

1. **不動産情報ライブラリのAPIキーを取得する**
   - https://www.reinfolib.mlit.go.jp/api/request/ から利用申請してください。
   - 個人情報（氏名・メールアドレス・利用目的）を入力すると、審査後おおむね5営業日程度でメールにてAPIキーが届きます。
2. **Python 3 がインストールされていること**を確認してください（`python3 --version`）。追加のライブラリのインストールは不要です（標準ライブラリのみで動作します）。

## セットアップ

```bash
cd kitakyushu-yoto-tool
cp config.example.json config.json
```

`config.json` を開き、`reinfolib_api_key` に取得したAPIキーを貼り付けて保存してください。

```json
{
  "reinfolib_api_key": "実際に発行されたAPIキー"
}
```

`config.json` の代わりに環境変数 `REINFOLIB_API_KEY` を設定して起動することもできます。

`config.json` にはAPIキーという機密情報が入るため、Gitにコミットしないでください（`.gitignore` で除外済みです）。

## 起動方法

```bash
python3 server.py
```

起動したら、ブラウザで以下を開いてください。

```
http://127.0.0.1:8765/
```

住所欄に調べたい物件の住所（例: 北九州市小倉北区浅野三丁目1-1）を入力して「検索する」を押すと、用途地域・建ぺい率・容積率が表示されます。

終了するには、サーバーを起動しているターミナルで `Ctrl+C` を押してください。

## 仕組み（技術メモ）

1. ブラウザの入力住所を `server.py` が受け取り、国土地理院の住所検索API（`msearch.gsi.go.jp`）で緯度経度に変換します。
2. 緯度経度からXYZタイル座標（ズームレベル15）を計算します。
3. 不動産情報ライブラリAPI「XKT002（用途地域）」にAPIキー付きでリクエストし、該当タイルの用途地域ポリゴン（GeoJSON）を取得します。
4. 取得したポリゴンの中から、対象地点を含むものを判定（点内判定）し、用途地域名・建ぺい率・容積率などを返します。

不動産情報ライブラリAPIはブラウザから直接呼び出すとCORSでブロックされ、またAPIキーをフロントエンドに埋め込むのはセキュリティ上好ましくないため、このサーバーがAPIキーを保持し、代理でリクエストする構成にしています。
